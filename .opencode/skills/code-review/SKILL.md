# 代码检视规范

## 目标

用**最少的人类注意力**，找准**会导致故障、安全风险或长期维护负担**的问题。

检视的价值不在"找出所有可改进点"，而在**信噪比**：报十条无关痛痒的问题，等于没报。

## 开始前必须做的三件事

1. **取变更**：`git diff <base>...HEAD` 或 `gh pr diff <PR号>`；确认你看到的是**本次变更**，不是整个仓库。
2. **补上下文**：对每个被修改的函数/类，至少看它的**调用方**和**依赖的接口定义**。只看 diff 会误判——被删掉的校验可能在别处补上了，新增的参数可能已有默认值。
3. **确认意图**：从 PR 标题、描述、commit message 推断作者想做什么。**报告"实现与意图不符"比报告"代码不好看"有价值得多**。

## 检视顺序（按重要性，不要跳序）

| 序 | 维度 | 关注什么 |
|---|---|---|
| 1 | **正确性** | 边界条件、空值/未定义、类型不匹配、并发与竞态、时区与编码、资源释放、错误处理分支是否被吞掉 |
| 2 | **安全** | 注入（SQL/命令/模板）、越权与认证缺失、敏感信息硬编码、路径穿越、不安全反序列化、新增依赖的可信度 |
| 3 | **可靠性** | 失败重试与超时、幂等性、状态一致性、异常路径的可观测性 |
| 4 | **可维护性** | 命名误导、重复逻辑、过度抽象、隐式耦合、复杂逻辑缺注释 |
| 5 | **风格** | **仅当项目有明确约定时**提及（如 linter 规则、语言惯例），否则不报 |

## 分级标准（业界通行的 blocking / non-blocking / nit）

| 级别 | 定义 | 处理建议 |
|---|---|---|
| 🚫 **Blocker** | 会导致错误结果、数据损坏、安全漏洞或线上故障 | 必须修复后才能合并 |
| ⚠️ **Major** | 有明确风险或显著劣化，但不会立即出错 | 建议本次修复 |
| 💡 **Minor** | 可读性、重复代码、可简化 | 可后续跟进 |
| 🔤 **Nit** | 纯个人风格偏好 | **默认不报**；同类问题超过 5 处时合并成一条附注 |

**分级纪律**：
- 拿不准是 Blocker 还是 Major 时，降一级并说明"需人工确认"
- **风格问题永远不进 Blocker**
- 同一个根因在多处出现，只报一次并注明影响范围

## 输出格式（严格遵循）

第一行必须是 `<!-- ai-review -->`（用于评论幂等更新），然后：

```markdown
## 🤖 AI 代码检视 · PR #<编号> <标题>

- 变更：`<head>` → `<base>` · +<增>/-<删> · <N> 个文件
- 检视模式：agent（含跨文件上下文）
- 检视时间：<YYYY-MM-DD HH:MM:SS>（北京时间）

### 结论

<一句话说清"能不能合并、为什么"> · 等级：<✅ 通过 | ⚠️ 建议改进 | 🚫 需修改>

### 必须修复（Blocker）

| 位置 | 问题 | 影响 | 建议 |
|---|---|---|---|
| `path:line` | <问题本质> | <会导致什么> | <怎么改> |

（没有则写：无）

### 建议改进（Major / Minor）

| 级别 | 位置 | 问题 | 建议 |
|---|---|---|---|
| ⚠️ Major | `path:line` | ... | ... |
| 💡 Minor | `path:line` | ... | ... |

（没有则写：无）

### 亮点

- <真正值得肯定的设计取舍，最多 2 条；没有则整节省略>
```

## 禁止事项

| 禁止 | 原因 |
|---|---|
| 评论未变更的代码 | 超出本次检视范围，制造噪音 |
| 复述 diff 内容 | 作者已经知道，浪费注意力 |
| 同一问题重复报告 | 一个根因报一次 |
| "建议加注释/改名"这类无信息量意见 | 除非命名确实误导 |
| 猜测未经验证的调用链 | 说明"需人工确认"，不要编造 |
| 把风格偏好标为 Blocker | 破坏分级公信力 |
| 输出 diff 原文或大段代码引用 | 报告要短于 diff |

## 自检（提交报告前）

1. 每条问题都能定位到**具体文件与行号**吗？
2. 每条 Blocker 都能说清**会导致什么后果**吗？
3. 有没有"这条其实是猜测"却写成确定结论的？
4. 报告长度是否**明显短于** diff？（超过 1.5 倍说明啰嗦）
5. 如果结论是"通过"，是否真的**没有** Blocker？
